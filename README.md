# Morph and Motion Cameras

A Blender add-on (Blender 4.2 or later) with two cameras:

- **Morph Camera**: a camera that travels through a list of cameras, driven by a single Blend value.
- **Motion Camera**: a camera that follows any object or camera as if a camera operator were carrying it (footsteps, hand-held shake, body lag).
